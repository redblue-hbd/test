# 品川区 花粉年間推移アプリ

Yahoo天気から品川区の花粉データ（スギ・ヒノキ）を取得し、
年間推移をインタラクティブなグラフで表示するWebアプリ。

## セットアップ

```bash
cd pollen_app
pip install -r requirements.txt
playwright install chromium
python app.py
```

ブラウザで http://localhost:5001 にアクセス。

## 使い方

1. **デモデータ** ボタン → 今シーズンのサンプルデータを生成してグラフを確認
2. **最新データ取得** ボタン → Yahoo天気を実際にスクレイピング（30秒〜1分）
3. グラフは毎日「最新データ取得」を押すことでデータが蓄積され、年間推移が完成する

## 操作

| 操作 | 説明 |
|------|------|
| 年セレクト | 表示する年を選択 |
| 表示種別 | スギ・ヒノキの表示切替 |
| グラフ種類 | 折れ線 / 棒グラフ |
| 期間フィルター | 月単位に絞り込み |
| マウスホイール | グラフのズーム |
| ドラッグ | グラフのパン（横スクロール） |
| ズームリセット | ズームを元に戻す |

## データ

- 取得先: https://weather.yahoo.co.jp/weather/pollen/3/13/13109/
- 保存先: `data/history.json`（累積保存）
- 花粉レベル: 0=なし / 1=少ない / 2=やや多い / 3=多い / 4=非常に多い
